# Jarvis appearance artwork

Six character atlases use a 2 × 2 grid: listening (top left), thinking
(top right), speaking (bottom left), success (bottom right).
The other ten files contain one isolated abstract object.

These transparent WebP assets were generated from the approved concepts in
`docs/avatar-concepts/`. They are artwork for a 2D animation renderer, not rigged
3D models. Original uploaded concepts remain available in the conversation.

Default appearance: `nova_bot`. Appearance IDs are independent of agent IDs.
